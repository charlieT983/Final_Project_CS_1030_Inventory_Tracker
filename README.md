## How to run the program 
1. When the program starts, it loads your inventory from inventory.csv (if the file exists).
2. Enter the amount at which an item counts a low in stock.
3. Choose what to do by typing one of the given options (add / low / remove/ done).

## The Inventory File 
- The file is created automatically when you type done. 
- It's saved in the same folder you ran the program from.
- It has two columns: Item and Amount.
- The program only saves when you type done. If you close the program another way, the changes from that run are lost.

## Opening and Editing the File in Excel
1. Go to the project folder and double-click inventory.csv. If it doesn't open in Excel, right-click it and choose Open with Excel
2. You can change amounts, add new items (the name in column A and a whole number in column B), or delete rows.
3. When you save, keep the CSV format if Excel asks. Don't save it as an Excel Workbook (the program can't read .xlsx files)
4. Close Excel before you run the program again.
 
## Some Issues I ran into 
- You might have to run the program twice in order for it to show you the csv file
- Sometimes the file won't show up in your folder
